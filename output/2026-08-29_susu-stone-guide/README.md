## 감수에서 지켜낸 안전선 (효능/과장/미신 방지)
- 원석 = **효능 아닌 '리마인더/상징'**. "돈·건강·운 바꿔주는 물건이 아니라 매일 떠올리게 해주는 리마인더" 명시(약사법·표시광고법 방패).
- 특정 석명(아벤츄린·라피스 등) 카탈로그 제시 **삭제** → **색 중심**으로 일반화("초록빛 돌·남색 돌", "정해진 판매목록 아니라 색 감각 잡는 단계"). 실제 취급 원석 라인업(B 보류)과 충돌 회피.
- 부족 오행 **단정 금지** → "힌트가 있어요/프로필에서 확인" 열린 톤(정확 판정은 사주 확인으로 전환).
- 가짜 예약/가격/링크 **창작 금지** → CTA는 "프로필 링크 확인"으로만.
- 명리 감수: 오행-색 매칭 통념과 일치(목=초록, 화=빨강, 토=노랑, 금=흰색, 수=남색). 확인됨.
- 캡션 해시태그는 **프로젝트 고정 5개**로 사용(synth가 제안한 다른 태그 세트는 규칙 위반이라 폐기).
